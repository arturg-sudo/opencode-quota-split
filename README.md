# quota-split

Локальный страж лимитов OpenCode Go. Считает только провайдер `opencode-go`,
ведёт скользящие окна 5 часов / 7 дней / 30 дней и не пускает новый промпт,
когда окно исчерпано.

По умолчанию лимиты — половина DeepSeek V4.1 Flash: $10 / $25 / $50.

## Установка

1. Скопируй папку `quota-split` в:

```
~/.config/opencode/local-plugins/quota-split
```

Windows: `C:\Users\<ты>\.config\opencode\local-plugins\quota-split`

2. Добавь в `~/.config/opencode/opencode.jsonc`:

```jsonc
{
  "plugins": [
    {
      "package": "./local-plugins/quota-split",
      "options": {
        "providerID": "opencode-go",
        "limits": { "h5": 10, "d7": 25, "d30": 50 }
      }
    }
  ]
}
```

3. Перезапусти OpenCode.

4. Убедись, что Go подключён: `/connect` → OpenCode Go.

## Что видно

- Строка в футере TUI: `Go 5h $1.20/$10 · 7d $4.00/$25 · 30d $9.00/$50`
- OpenCode Desktop: такая же полоса внизу окна (`window.bottom`) и команда
  «Refresh Go split quota» в палитре.
- `/quota_split` в TUI — детали (проценты и статус блокировки).
- Цвет: серый → янтарный при 80% → красный при 100%.

## Как считается

- Событие `session.usage.updated` даёт накопленный `cost` сессии.
- Плагин берёт только дельту и только для сессий с провайдером `opencode-go`.
- Окна скользящие: 5ч, 7д, 30д от текущего момента.
- При старте подхватываются сессии за последние 30 дней, чтобы не потерять расход.
- Состояние хранится в storage плагина и переживает перезапуск.

## Блокировка

На `session.hook("prompt")`. Если любое окно >= лимита, промпт не принимается
и показывается ошибка с текущими цифрами. Уже идущий запрос не обрывается —
следующий промпт уже не пройдёт.

## Ограничения

- Это локальный контроль, а не серверный. Ключ Go лежит в OpenCode, и его
  можно использовать мимо плагина.
- На двух машинах счётчики независимы. Если оба честно упираются в свои
  $10/$25/$50, суммарно выходит ~100% квоты, но ровно 50/50 не гарантируется.
- Реальные окна Go всё равно видны в `/quota` (opencode-quota) и в Console.
- Если провайдер сессии не определяется, её расход не учитывается.

## Изменение лимитов

В `opencode.jsonc` → `options.limits`. После правки плагин перезагрузится сам.
